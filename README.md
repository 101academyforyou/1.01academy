# 1.01academy

> 每天進步 1%，一年後強大 37 倍

精簡的線上課程網站，清爽科技風格（支援深色模式與手機版）。

## 功能

1. **瀏覽課程**：首頁列出所有課程，可依分類篩選或搜尋
2. **課程介紹**：課程說明、學習重點、章節列表、免費試看
3. **登入 / 註冊**
4. **購買**：填信用卡資料即可開通課程（目前為示範模式，不會實際扣款）
5. **上課**：影片播放、單元列表、學習進度（看完自動標記完成並跳到下一單元）
6. **我的課程**：已購買的課程與進度

## 開啟方式

不需要安裝任何東西，在資料夾中執行：

```bash
python3 -m http.server 8000
```

再打開 http://localhost:8000 。也可以直接放到 GitHub Pages 等靜態網站空間。

## 檔案

```
index.html      頁面外框
css/style.css   樣式
js/data.js      課程資料 ← 新增/修改課程改這裡
js/app.js       所有頁面與功能
```

### 新增課程

在 `js/data.js` 的 `COURSES` 裡複製一筆課程修改即可。每個單元格式為：

```js
['單元id', '單元標題', 秒數, 是否免費試看, '影片網址或檔名']
```

## 注意

目前帳號與購買紀錄只存在使用者自己的瀏覽器（localStorage），付款也是模擬的。
正式收費前需要：串接金流（例如綠界 ECPay、藍新、TapPay）、後端資料庫與會員系統，並把影片放到有保護的影音平台。
